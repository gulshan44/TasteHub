# TasteHub

TasteHub is a SaaS-based Restaurant Operating System designed for small and medium-sized restaurants.

## Overview

TasteHub aims to bring essential restaurant operations into a single platform.

Restaurants will be able to manage:

- Menu
- Tables
- QR Ordering
- Orders
- Kitchen Operations
- Billing
- Inventory
- Customers
- Analytics
- Business Insights

## Core Users

- Super Admin
- Restaurant Owner
- Restaurant Manager
- Restaurant Staff
- Kitchen Staff
- Customer

## Technology Stack

### Frontend

- React
- Vite
- Tailwind CSS

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
